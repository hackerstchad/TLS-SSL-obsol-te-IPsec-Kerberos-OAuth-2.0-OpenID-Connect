## Protocoles couverts

- **TLS (Transport Layer Security)** : chiffrement des communications transport, successeur de SSL.
- **SSL (Secure Sockets Layer)** : protocole obsolète, ancêtre de TLS.
- **IPsec (Internet Protocol Security)** : sécurisation couche 3, VPN.
- **Kerberos** : authentification centralisée par tickets.
- **OAuth 2.0** : délégation d'autorisation.
- **OpenID Connect** : authentification fédérée au-dessus d'OAuth 2.0.
